# 🍊 Mikan Engine

### 🧩 Small pieces. Whole worlds.

**Mikan Engine** is an open-source game engine project that emphasizes a modular design, solid systems engineering, and a journey from 2D to 3D.

We think a game engine should be more than just a bunch of features. Its systems need to work together, be easy to understand, and provide a strong base for developers to craft their own worlds. 🌍

## 🚀 What We Build

Mikan's all about evolving into a powerful, modular game engine.

- 🎨 **Rendering** — 2D graphics and the groundwork for richer visuals.
- 🗺️ **World Building** — tilemaps and tools for creating game worlds.
- 🧱 **Collision & Physics** — systems for object interactions and physical simulations.
- 📦 **Asset Management** — organized handling of game resources and content.
- ⚙️ **Engine Infrastructure** — reusable systems that are designed to work seamlessly together.
- 🌌 **3D Capabilities** — a long-term goal built on a solid 2D foundation.

We’re focused on building integrated, reliable systems instead of just collecting random features.

## 🦀⚙️ Our Technology

Mikan is built with **Rust, C++, and C**, each for a specific reason.

- 🦀 **Rust** — our core implementation language for safety, reliability, and maintainability.
- ⚙️ **C++** — a primary language for robust engine functionality.
- 🔩 **C** — the low-level backbone for platform-specific components and tight interfaces.

Rust and C++ handle the engine core, while C supports the lower-level foundation. We choose our boundaries based on what’s technically needed, not based on language preferences.

## 💡 Our Philosophy

- 🧩 **Modularity first** — clear boundaries and focused components.
- 🔗 **Integration matters** — systems should function as a cohesive engine.
- 🎯 **Correctness before complexity** — establish a reliable base before adding unnecessary complexity.
- 🧪 **Quality through testing** — validate behavior and protect existing functionality.
- ⚡ **Performance with purpose** — measure, understand, and optimize.
- 🌱 **Build incrementally** — grow from a solid 2D base toward 3D.
